# Практическое задание №3: Основы sklearn на примере KNN

## Описание проекта

Этот проект содержит решение практического задания по курсу "Машинное обучение. ВМК МГУ". Основная цель — познакомиться с библиотекой `scikit-learn` на примере методов ближайших соседей (KNN), освоить техники нормализации данных и кросс-валидации.

## Содержание

*   **scalers.py**: Модуль с реализацией классов `StandardScaler` и `MinMaxScaler` для нормализации данных.
*   **Копия_блокнота_Base_Sklearn_knn_normalize_cv_2025_2026_ipynb_2.ipynb**: Jupyter Notebook с решением всех заданий, включая визуализацию, выбор гиперпараметров и обучение модели.

## Основные этапы работы

1.  **Реализация скейлеров**: Созданы собственные классы для стандартизации и масштабирования признаков.
2.  **Визуализация KNN**: Построены разделяющие поверхности для алгоритма KNN на синтетических данных, продемонстрировано влияние нормализации.
3.  **Кросс-валидация**: Проведен подбор гиперпараметров для KNN-регрессии на датасете California Housing с использованием `GridSearchCV`.
